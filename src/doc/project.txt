PROJECT CONVENTIONS

1) Tech Stack
- UI Framework: Ant Design (Antd)
- Styling: TailwindCSS

Nguyên tắc chung:
- Ưu tiên tái sử dụng component của Antd để đảm bảo đồng bộ UI/UX.
- Sử dụng Tailwind cho layout/spacing/utility classes; hạn chế viết CSS thủ công nếu không cần thiết.


2) i18n (Internationalization)
Mục tiêu:
- Hỗ trợ đa ngôn ngữ và dễ dàng mở rộng nội dung theo locale.

Quy ước:
- Tất cả text hiển thị ra UI phải lấy từ file messages (không hard-code string trực tiếp trong component).
- Thêm/chỉnh sửa bản dịch tại: /messages/vi.json (và các file locale khác nếu có).
- Tham khảo cách dùng i18n tại: /src/app/page.tsx.

Khuyến nghị:
- Key đặt theo nhóm tính năng (feature-based) và có ngữ nghĩa rõ ràng.
     Ví dụ: "auth.login.title", "common.save", "profile.form.fullName".


3) Styling & Design Tokens
Mục tiêu:
- Đảm bảo giao diện đồng nhất, dễ maintain và tránh “lệch màu / lệch style” giữa các màn.

Quy ước:
- Layout:
     - Ưu tiên sử dụng container đã được setup sẵn bằng Tailwind để đảm bảo kích thước và breakpoint thống nhất.
- Component:
     - Dùng component Antd cho các phần UI phổ biến (Button, Form, Modal, Table, ...).
- Màu sắc:
     - Không set màu thủ công tùy tiện (tránh dùng mã màu rải rác trong code).
     - Các màu chủ đạo/tokens đã được cấu hình sẵn; nếu cần bổ sung/chỉnh sửa token thì cập nhật tập trung.
     - Danh sách màu custom nằm trong globals.css.

Cách dùng token (ví dụ):
- Dùng class Tailwind theo token đã khai báo:
     - text-primary / text-secondary / text-muted
     - bg-primary / bg-secondary / bg-muted

Ví dụ:
<h1 className="text-primary">Title</h1>


4) Checklist trước khi merge
- Không hard-code text (đã đưa vào messages).
- Không hard-code màu sắc (đã dùng token).
- UI dùng Antd nhất quán; layout dùng Tailwind hợp lý.
